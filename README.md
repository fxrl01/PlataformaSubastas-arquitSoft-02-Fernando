# Plataforma de Subastas en Tiempo Real
Fernando Olivares Chuhui
## Descripción
Plataforma transaccional de subastas que procesa pujas en tiempo real, garantizando el orden de llegada mediante RabbitMQ y aplicando IA para evaluar la confianza.
## Caso de estudio
Plataforma de subasta propia con enfoque en Arquitectura Limpia/Hexagonal.
## Curso
Arquitectura de Software

🗄️ 1 Sola Base de Datos: PostgreSQL 16 (No 2 BDs)

PostgreSQL 16 es la única base de datos donde se guarda todo el sistema. Redis NO es una segunda base de datos: solo vive dentro del backend como semáforo temporal de 1.5s y megáfono de salas WebSocket.

💳 Pasarela de Pagos Stripe + Servicios Externos

Integración explícita con Stripe API (retención preventiva de garantía Pre-Auth Hold, cobro al ganador y liberación automática), Azure Blob Storage / Cloudflare CDN & KYC (fotos del lote y PDF pericial) y Google Gemini IA.

🚀 Monolito Modular para Desarrollo Continuo

Un único servidor en Go 1.23+ organizado internamente en 6 Módulos de Negocio independientes. Fácil de probar, rápido de desplegar y sin la complejidad de mantener múltiples microservicios.

Responsabilidades Clave

  • PostgreSQL 16 es la única base de datos persistente.
  • Redis solo actúa como semáforo en memoria (1.5s) y difusor WebSocket.
  • Stripe API gestiona la retención y liberación de garantías en tarjeta.

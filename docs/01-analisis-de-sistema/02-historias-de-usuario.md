# Historias de usuario — LiveBid

Formato: **Como [actor], quiero [acción], para [beneficio].**

## Pujador / Espectador

| ID | Historia de usuario |
|---|---|
| HU01 | Como pujador, quiero explorar las subastas activas y programadas, para decidir a cuál unirme. |
| HU02 | Como pujador, quiero ver la transmisión en vivo de una subasta, para evaluar el ítem antes de pujar. |
| HU03 | Como pujador, quiero enviar una puja mientras veo el video en vivo, para intentar ganar el lote. |
| HU04 | Como pujador, quiero ver el precio actual actualizado en tiempo real, para saber si mi puja fue superada. |
| HU05 | Como pujador, quiero recibir una notificación clara de si gané o perdí un lote, para saber si debo pagar. |
| HU06 | Como pujador, quiero consultar mi historial de pujas y pagos, para llevar control de mi actividad. |
| HU07 | Como pujador nuevo, quiero verificar mi identidad antes de pujar por montos altos, para dar confianza al resto de participantes del evento. |

## Rematador / Organizador

| ID | Historia de usuario |
|---|---|
| HU08 | Como rematador, quiero crear una subasta y elegir su formato (ascendente, descendente, sellada, benéfica), para adaptarla al tipo de evento que organizo. |
| HU09 | Como rematador, quiero registrar los lotes con su precio base e incremento mínimo, para que el sistema valide las pujas correctamente. |
| HU10 | Como rematador, quiero iniciar y cerrar la transmisión en vivo desde la plataforma, para controlar el evento de principio a fin. |
| HU11 | Como rematador, quiero cerrar un lote manualmente o que se cierre automáticamente por temporizador, para tener flexibilidad según el tipo de evento. |

## Vendedor / Consignante

| ID | Historia de usuario |
|---|---|
| HU12 | Como vendedor, quiero registrar un ítem con fotos, descripción y precio de reserva, para que el rematador pueda incluirlo en un evento. |
| HU13 | Como vendedor, quiero recibir el pago automáticamente una vez cerrada la venta, para no depender de una gestión manual. |

## Administrador

| ID | Historia de usuario |
|---|---|
| HU14 | Como administrador, quiero ver alertas generadas por el sistema de detección de fraude, para intervenir antes de que una puja sospechosa gane un lote. |
| HU15 | Como administrador, quiero suspender la cuenta de un usuario reportado, para proteger la integridad de la plataforma. |
| HU16 | Como administrador, quiero consultar el registro de pujas con su orden verificado, para tener una fuente de verdad ante una disputa. |
